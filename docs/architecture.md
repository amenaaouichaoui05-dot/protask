
# ProTask — Global Architecture

## 1. Project Overview

ProTask is a collaborative project management
platform designed to help teams organize projects,
distribute tasks and monitor progress.

## 2. Architecture Type

ProTask follows a client-server architecture.

The application is divided into:
- Frontend
- Backend
- Database

## 3. Frontend

Technology: React + TypeScript + Vite

Main modules:
- Dashboard
- Project Management
- Task Management
- Kanban Board
- User Management
- User Profiles

## 4. Backend

Technology: Node.js + Express + TypeScript

Main layers:
- Routes
- Controllers
- Services
- Middlewares
- Configuration

## 5. Database

The database will store:
- Users
- Projects
- Tasks
- Comments
- Notifications

The database technology will be selected
with the development team.

## 6. Communication

The frontend communicates with the backend
through REST API endpoints.

Data is exchanged using JSON over HTTP.

## 7. Future AI Integration

Possible features:
- Task recommendations
- Workload analysis
- Delay prediction
- Project progress analysis
